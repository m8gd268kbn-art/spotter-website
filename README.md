# Webseite zu Spotter

Die zwei oeffentlichen Seiten, die der App Store verlangt:

- `index.html` — Support
- `datenschutz.html` — Datenschutzerklaerung

Veroeffentlicht ueber GitHub Pages unter <https://spotter-app.de>.

**Quelle ist `AppStore/website/` im Spotter-Projekt.** Dieses Repository ist
die veroeffentlichte Kopie; Aenderungen gehoeren zuerst dorthin, damit die
beiden nicht auseinanderlaufen.

Der Text der Datenschutzerklaerung ist ein ENTWURF und enthaelt noch
Platzhalter in eckigen Klammern. Er ist vor der Veroeffentlichung der App
juristisch zu pruefen.
